# InmunoGuía — Inmunodeficiencias primarias

Herramienta web educativa en español con contenidos organizados de:
- [Immune Deficiency Foundation](https://primaryimmune.org/)
- [Jeffrey Modell Foundation — Information Booth](https://www.info4pi.org/information-booth/)
- [FUMENI](https://fumeni.org.mx/)

## Qué contiene
- Menú desplegable por organización, con submenús para **médicos**, **estudiantes de medicina** y **familiares y pacientes**.
- 36 fichas originales y enlaces al material de origen.
- Filtros temáticos, búsqueda, diez señales clásicas de alerta y mini-quiz.
- Ruta educativa de sospecha, evaluación, referencia y seguimiento.
- Funciona como HTML estático, sin dependencias, cuentas o base de datos.

## Cómo publicar con GitHub Pages
El sitio está en `/inmunodeficiencias/index.html`; se conserva sin cambios el proyecto previo de la raíz.

1. Ve a **Settings > Pages** de este repositorio.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona **main** y **/(root)** y pulsa **Save**.
4. Una vez desplegado GitHub Pages, la dirección prevista es:
   **https://munozsantiago3-star.github.io/rutavih/inmunodeficiencias/**

> La URL sólo funciona cuando GitHub Pages está habilitado y el despliegue termina correctamente.

## Uso local
Descarga `index.html` y ábrelo en cualquier navegador moderno. No requiere instalación.

## Alcance
Esta es una síntesis editorial independiente, no afiliada a las organizaciones enlazadas. No reproduce los sitios completos ni sustituye la evaluación médica, la práctica clínica individualizada ni guías vigentes. Los ejercicios no diagnostican ni almacenan respuestas.
